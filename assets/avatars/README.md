# Hamster avatar PNG assets

- 形式: 透過 PNG
- 推奨キャンバス: 512 x 512
- 同じ体型では、顔・胴体・足元の基準位置を統一してください。
- 初期構成は 10外見 x 8状態 = 80枚です。
- PNGが未配置でも、アプリは `assets/images/roi.png` へフォールバックします。

## 状態

- `happy`
- `stable`
- `worried`
- `alert`
- `insufficient_data`
- `environment_discomfort`
- `activity_high`
- `condition_concerned`

詳細なパスは `avatar_asset_manifest.csv` を参照してください。
