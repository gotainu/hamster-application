# 特商法の事業者情報・請求開示方式（2026-11-21、未公開）

## 決定と今回の範囲

氏名・住所・電話番号は、消費者からの請求に応じて開示する方式を採用する。公開案には、請求窓口と、申込みの意思決定に先立って十分な時間的余裕をもって確認できるよう、書面又は電子メール等で遅滞なく提供する旨を記載する。

公開窓口は既存の `gotainu@gmail.com` を、問い合わせ・特商法開示請求・契約課金・不具合で共用する。自宅住所・個人電話を常時公開する方針や、バーチャルオフィスの契約は採用しない。バーチャルオフィスは必要になった際の将来検討にとどめる。メール差出人の表示は現在の HamCare／Go / hamster well-being 等のブランド表示を維持し、個人本名へ変更しない。請求に対して開示する法定の事業者情報と、メール差出人のブランド表示を混同しない。

この文書は公開前の運用手順案である。文言を用意したことをもって、実際の開示体制を検証済み、表示省略の要件を充足済み、本番公開可能とは扱わない。事業者の氏名・住所・電話の実値は、本書、監査台帳、チャット、テストデータへ転記しない。個人値をリポジトリへ追加しない。

対象は特商法ページ、サポートページと本書。氏名・住所・電話の公開切替、メールの実送信、本番サイトの配備、Stripe・既存契約・課金機能の変更は行わない。料金表示は確定済みの「月額550円」とする。

## 公開案の内容

- 特商法ページに、氏名・住所・電話を請求開示する旨、購入前から請求できる旨、提供方法と提供時期、既存のメール窓口を明示する。
- 件名を入力済みのメールリンクを設け、請求方法を分かりやすくする。特定の件名でない請求も受け付ける。
- サポートページにも事業者情報の開示窓口を設け、通常の不具合対応を順次返信する案内と区別する。
- 登録、ログイン、有料契約、購入の確約を開示の条件にしない。開示が必要な人に、情報受領前の申込みを求めない。

## 請求を受けた際の手順

1. 既存のサポート窓口で「事業者情報の開示請求」と分かる連絡を受け付ける。表題の完全一致や購入済みであることを条件にしない。
2. 個人事業者の氏名は戸籍上の氏名又は商業登記された商号、住所は現に活動している正確な住所、電話は確実に連絡を取れる番号を、運営者が管理する非公開の正本で確認する。法人である場合の名称・責任者等の要件は、実際の事業者形態に合わせて確認する。屋号やサイト名だけ、番地の欠落、私書箱だけ、連絡不能な電話で代替しない。
3. 確認した広告表示事項を、請求者が保存・確認できる書面又は電子メール等で遅滞なく提供する。受領確認や本ページへのリンクだけをもって開示完了にしない。購入判断の前に十分な時間的余裕をもって確認できる状態にする。
4. 不達・誤送信・問い合わせの行き違いを確認し、未達のまま完了にしない。相手が取引を確約しないことを理由に開示を拒まない。
5. 受信日時、対応日時、送信成否と対応完了の事実は必要な範囲で非公開に記録する。事業者の個人値、請求者のメール本文・個人情報を開発用の記録やGitへ複製しない。

## 本番公開前に運営者が確認する事項

| 項目 | 必要な確認 | 現在の証拠・状態 |
| --- | --- | --- |
| 開示情報の正本 | 正確な氏名・住所・連絡可能な電話を非公開で管理し、その所在を担当者が把握している | 実値を取得・転記していないため未検証 |
| 対応責任者 | 誰が受信を確認し、誰が開示し、不在時にどう引き継ぐか | 本文作成のみ。本人の実体制確認が必要 |
| 受信と対応 | 受付窓口の継続利用、確認頻度、不達時の対応を含め、請求に遅滞なく対応できること | 実送受信・担当者運用は未検証 |
| 購入前の提供 | アカウントや決済を条件にせず、申込判断前に十分な余裕をもって情報が届くこと | 公開案の文言を整備。実運用は未検証 |
| 開示経路 | 正確な情報を保存可能な書面又は電子メール等で提供し、請求者に到達すること | 実送信0。検証時にも個人値をGitへ保存しない |
| 法務表示への到達 | LP・申込画面から特商法ページ、同ページから請求窓口へ到達できること | 親タスクのローカル参照・表示確認で記録する |

この表の未検証事項は、HTMLの文言変更だけでは完了しない。運営者による確認後、確認日と確認した事実だけを追記する。公開可否の最終判断では、実際の提供体制を含めて確認する。

## 一次資料

HamCare公式Webからの有料申込みを有償の役務提供として照合した。消費者庁Q1は有料情報配信等の有償役務も通信販売の対象としており、Q15/Q17の請求開示条件に沿った方式を採用する。価格・更新・解約・返金等の他の表示は維持し、事業者情報を省略したことで他の必要表示まで省略できるとは扱わない。

2026-11-21の作業時に参照した消費者庁の説明では、Q15とQ17が氏名・住所・電話の請求開示による表示省略の条件を示している。請求に応じて遅滞なく提供する旨の表示に加え、実際に提供できる措置が必要であり、提供時期は取引実態に即して申込判断前に十分な余裕をもつ必要がある。本書の運用上の注意は、この要件を具体化した作業案であり、実運用を確認した事実の記録ではない。
