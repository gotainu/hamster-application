## テストラウンド

### 1回目: 導入と基本記録

- [ ] Playストアのテストリンクからインストールできる
- [ ] 新規登録、ログイン、ログアウト
- [ ] ペットプロフィールと飼育環境を登録できる
- [ ] 今日の様子、体重、走行距離を保存できる
- [ ] アプリ再起動後も記録が表示される

### 2回目: 継続利用と有料機能

- [ ] グラフと傾向表示を確認する
- [ ] AI相談を送信し、履歴を確認・削除する
- [ ] 通知許可と通知設定を確認する
- [ ] 有料プランの料金・自動更新条件・解約導線を確認する
- [ ] SwitchBotを利用できるテスターは連携・解除を確認する

### 3回目: 安全性とアカウント管理

- [ ] オフラインや通信失敗時に操作不能にならない
- [ ] 権限を拒否しても不要なクラッシュがない
- [ ] プライバシーポリシー、利用規約、サポートページが開く
- [ ] アカウント削除の説明と処理を確認する
- [ ] AI相談に医療行為の断定を避ける注意表示がある
