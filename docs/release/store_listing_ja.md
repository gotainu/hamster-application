## 詳細説明

Hamster Careは、ハムスターの毎日の記録と飼育環境をひとつにまとめ、いつもと違う変化に気づきやすくするための飼育サポートアプリです。

### 主な機能

- 今日の様子や気になる点をかんたんに記録
- 体重と回し車の走行距離を記録し、期間ごとの変化を表示
- SwitchBot温湿度計と連携した温度・湿度の自動記録
- 温湿度、活動量、体重の推移と傾向をグラフで確認
- 飼育環境や記録を踏まえたAI相談
- 高温・低温・高湿度など、気になる環境変化の通知
- ペットプロフィールと飼育環境の管理

### 無料体験と体験終了後

カード登録不要の無料体験では、本人の開始操作から21日間、記録・変化の確認・AI相談などを試せます。AI相談は最大20リクエストです。体験開始時にStripe契約は作成されず、体験終了だけで自動課金されません。体験終了後に記録・変化の確認・AI相談を続けるには、有料プランが必要です。作成済みのうちの子レポートは、契約なしでも閲覧できます。

### 有料プラン

有料プランでは、SwitchBot連携、温湿度の自動記録、環境評価、異常検知通知、AI相談などを利用できます。購入前にアプリ内で料金と条件を表示し、解約後も支払済み期間の終了まで利用できます。

審査用補足（公開ストア説明へは貼り付けない）: Hamster Care Premium Planは月額500円（税込）、1か月ごとの自動更新です。カード登録不要の無料体験は本人の開始操作から21日間、AI相談は最大20リクエストです。開始時にStripe契約を作成せず、終了だけで自動課金しません。無料体験・終了後の説明は既存の記録／変化gateとプラン画面に照合済み。権限変更は行わない。10/25の本人承認後、App Store Connect版1.0.1へ詳細説明（本内部補足を除く）／キーワード／プロモーション文／support URLを保存し、再読取で原稿一致を確認。Privacy URLも保存済み。その後Google Playの掲載名／詳細説明も同じ原稿で保存PASS。既存store_assets/metadataの両説明txtも同期。両ストアのアプリ審査送信は未実施。

本アプリの評価やAI相談は、日々の観察を整理するための参考情報です。獣医師による診断や治療の代わりではありません。体調不良や緊急性のある症状が見られる場合は、動物病院へ相談してください。

SwitchBot連携機能の利用には、対応するSwitchBot温湿度計、ハブ、SwitchBotアカウントが必要です。
